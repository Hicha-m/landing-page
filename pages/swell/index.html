Non. C'est un concept indépendant inspiré de certains principes de communication visuelle, sans affiliation avec Swile.

Une maquette Figma éditable a été créée d'abord, puis une page statique HTML/CSS/JavaScript. Les sources et étapes figurent dans la documentation GitHub.
