## Propriété intellectuelle

Swell V2 est un exercice de design distinct. Le logo Swile, les visuels et textes marketing propriétaires, les témoignages clients réels et les captures du site source ne sont pas réutilisés dans `pages/swell-v2/`. Tous les montants de l'application sont fictifs. Aucune affiliation avec Swile.
